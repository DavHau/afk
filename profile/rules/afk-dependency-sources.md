# Dependency source code

When you need to understand how a dependency works, read its source rather
than guessing or relying on documentation alone.

1. First check `$HOME/projects/` for an existing checkout.
2. If it is not there, clone the project into `$HOME/projects/` and read it there.
3. Treat the source as the primary reference for behavior, APIs, and internals.
